## 运行

最省事的方式：双击 **`启动游戏.cmd`**。  
它会检查 `4173` 端口是否已有游戏服务；没有就启动 Vite，然后用默认浏览器打开：

- 本机：**http://127.0.0.1:4173/**
- 局域网：**http://<本机局域网 IP>:4173/**  
  例如本机以太网地址是 `192.168.0.55`，则访问 `http://192.168.0.55:4173/`。

Vite 已配置为监听 `0.0.0.0`，同一局域网设备可以直接访问；如果被 Windows 防火墙拦截，需要允许 Node.js / 端口 `4173` 的专用网络入站访问。

也可以手动运行：

```bash
npm install
npm run dev
```

打开终端里 Vite 输出的地址（通常为 `http://localhost:5173/`）。

如果端口被占用或受限：

```bash
npm run dev -- --port 4173
```

生产构建：

```bash
npm run build
npm run preview
```

## 当前可玩内容

- 第三人称默认（舒适优先） / 第一人称（V 切换）
- WASD 移动、鼠标视角、Pointer Lock
- 左键普攻（奥术弹，按住连发）
- Q 星弧飞弹（按住蓄力，松开放射）
- F 引力法阵（W 与移动冲突，因此绑定 F）
- E 折跃（8m 闪现 + 0.24s 无敌帧）
- R 天穹裂隙（2.5s 引导光束）
- 被动星辉印记：技能叠层，3 层后普攻引爆
- `Space` 跳跃：可躲 Boss 的地面重拳/冲击波，弹幕仍会命中
- 等级成长：1-20 级，提升伤害、攻速、冷却缩减、生命/法力
- Boss Rush v0.2.3a：星蚀守卫 3 轮轮回（1800 / 2160 / 2520 HP）/ 2 阶段
- 每次击败 Boss 后 3 选 1 星辉强化（8 个强化池）
- 竞技场边界、Boss 血条/阶段、计时、死亡重试、胜利结算与本地最快记录
- 星蚀守卫 Boss：追击、重拳、冲击波、扇形弹幕、登场/阶段转换演出
- 阶段 2 独立星蚀碎片：2 个可击杀召唤物，会发射弹幕
- 受击方向提示、低血警告、技能说明面板
- 生命 / 法力 / 冷却 / 目标血条 / 击杀 / 金币 HUD
- 伤害数字、命中标记、受击反馈、程序化音效
- 死亡倒计时与复活
- FPS / draw call / 三角形数量面板
- KayKit CC0 模块化场景：石板、拱门、柱廊、火把、旗帜、废墟
- 星辉峡谷视觉：渐变天空、星环、远山、星门、Bloom、雾
- KayKit 法师 / 骷髅战士模型与 idle / walk / cast / hit / death 动画
- 法师贴图运行时换色，统一为深蓝 / 金 / 星青

## 操作

| 输入 | 功能 |
|---|---|
| `W/A/S/D` | 移动 |
| `Space` | 跳跃（躲 Boss 地面伤害） |
| 鼠标 | 视角 |
| 鼠标左键 | 普攻（按住连发） |
| `Q` | 星弧飞弹（按住蓄力） |
| `F` | 引力法阵（按住显示落点，松开释放） |
| `E` | 折跃 |
| `R` | 天穹裂隙 |
| `V` | 第一 / 第三人称切换 |
| `Esc` | 暂停 / 释放鼠标 |
| 点击“继续” | 重新锁定鼠标 |
| 开始 / 暂停 → 舒适设置 | FOV、视角、灵敏度、武器晃动、屏幕震动、画质、隐藏武器 |

## 已知限制

- 这是 **Art Pass 1.0 第一版**，不是最终美术：角色比例、场景构图、火光/VFX 还会继续调。
- 目前是 Boss Rush v0.2.3a：1 个 Boss 的 3 轮轮回 + 3 选 1 + P0 表现打磨；还没有第二/第三个独立 Boss、小兵、防御塔、商店。
- 角色目前是“CC0 骨架 + 外观换色/换装”的过渡方案，不是全定制建模。
- 使用程序化占位音效。
- 仅面向桌面 Chrome / Edge / Firefox 键鼠；移动端未适配。
- 当前构建包含内联 Rapier WASM，包体偏大；后续可做拆包/压缩。
