# v0.2 下一阶段执行清单

> 起点：Art Pass 1.0 Look Dev 1 已完成。  
> 当前问题：玩法单一、场景/角色仍是第一版、**移动时晕 3D**。  
> 顺序原则：**先舒适度 → 再构图/角色 → 再玩法纵深 → 最后完整中路。**  
> 3D 晕动症未通过验收前，不进入大规模场景和玩法扩展。

---

## 0. 优先级总览

| 优先级 | 目标 | 预计 | 是否阻塞后续 |
|---|---|---|---|
| **P0** | 3D 舒适度基线：FOV、移动曲线、相机稳定、武器晃动、帧率稳定 | 2-3 天 | **是，必须先过** |
| **P1** | 星辉峡谷构图第二版 + 法师/守卫剪影 | 3-4 天 | 否，但影响观感 |
| **P2** | Combat 2.0：W/E/R + 被动 + 3 种敌人 + 5 波 | 5-7 天 | 否 |
| **P3** | 中路对决：小兵、塔、水晶、金币/经验、商店、AI | 10-14 天 | 否 |
| **P4** | 音频、UI 图标、性能、QA、发布 | 4-5 天 | 否 |

**建议先做 P0 的 2-3 天，做完立刻找 3-5 人试玩；通过后再做 P1/P2。**

---

# P0：3D 舒适度专项（最高优先级）

详细规格见 [`comfort-3d-spec.md`](./comfort-3d-spec.md)。

## C01 FOV 与相机默认值

- [ ] 默认垂直 FOV 从 80° 改为 **70°**
- [ ] 设置滑杆：60-90°
- [ ] 不做冲刺/受击 FOV 变化
- [ ] 相机 roll 永远为 0
- [ ] 默认关闭动态模糊/景深
- 验收：16:9 下水平 FOV 约 95-100°，边缘不再明显拉伸

## C02 移动曲线

- [ ] 最高速度 6.5 → **5.5 m/s**
- [ ] 加速 18-22 m/s²
- [ ] 减速 24-30 m/s²
- [ ] 斜向移动归一化
- [ ] 不做瞬间起步/瞬停
- 验收：起步/停止不“顶头”，连续走 2 分钟无突兀感

## C03 相机高度稳定

- [ ] 相机水平位置直接跟随
- [ ] 相机 Y 使用 `MathUtils.damp`，lambda 18-24
- [ ] 物理碰撞的微小 Y 抖动不传给镜头
- [ ] 第三人称相机弹簧臂平滑 + 墙体安全距离
- 验收：走路时准星不上下抖；贴墙第三人称不跳变

## C04 武器晃动

- [ ] 默认武器 bob = 0%
- [ ] 提供 0-100% 滑杆
- [ ] 施法后坐降低 30-50%
- [ ] 提供“隐藏武器”
- 验收：默认模式下视野边缘无持续摆动

## C05 舒适模式

- [ ] 一键预设：FOV 70、bob 0、震动 0、Bloom 低/关、静态暗角开
- [ ] 不改变移动速度/伤害/技能
- [ ] 设置写入 `localStorage`
- 验收：刷新后保留；开关前后差异明显但不影响玩法

## C06 设置面板

- [ ] 画面：画质、FOV、Bloom、暗角、帧率上限
- [ ] 舒适度：舒适模式、武器晃动、屏幕震动、视角平滑、隐藏武器
- [ ] 控制：鼠标灵敏度、反转 Y
- [ ] 音频：主音量/音乐/音效
- 验收：暂停菜单和开始界面都能进入设置

## C07 帧率稳定

- [ ] 固定 60Hz 模拟 + 渲染插值
- [ ] 连续 3 秒低于 55 FPS 自动降画质
- [ ] 低画质：关 Bloom、降阴影、像素比 1.25
- [ ] 首屏资产加载完成前禁用开始按钮（已做）
- 验收：目标设备 60 FPS，帧时间无明显尖峰

## C08 第三人称兜底

- [ ] 第三人称相机平滑
- [ ] 默认距离 4.5m，可调 3.5-6m
- [ ] 第三人称下隐藏第一人称武器 bob
- 验收：第一人称不适时，第三人称可以连续玩 15 分钟

## C09 3D 舒适度实测

- [ ] 3-5 人，至少 1 人平时容易晕 3D
- [ ] 每人 15 分钟：直线/横移/转身/战斗/自由探索
- [ ] 记录舒适度 1-5、是否头晕、何时不适、最难受动作
- [ ] 目标：至少 4/5 完成无明显恶心，平均舒适度 ≥4/5
- [ ] 如果仍晕：默认第三人称、速度 5.0、FOV 65、关 Bloom/震动

## C10 验收门禁

- [ ] P0 全部通过，才允许开始 P1/P2
- [ ] 不通过就继续调 P0，不靠“习惯一下”

# P1：构图与角色第二版

## V01 星门比例

- [ ] 当前星门仍偏大，缩小 15-25%
- [ ] 门柱从 6.8m 降到 5.5-6m
- [ ] 门后不要直接压住敌方目标
- 验收：第一人称中心视野不被门柱切割

## V02 墙体重复感

- [ ] 增加 3-4 种破损/倾斜墙段
- [ ] 每 5-6 段插入一个拱门/壁龛
- [ ] 减少连续蓝色方块
- 验收：沿路走 30 秒，两侧不出现明显复制粘贴

## V03 地面色调

- [ ] 当前地面偏蓝；增加暖色火盆反射/金色边缘
- [ ] 路面中段加入骨白/金色符文带
- [ ] 保持敌方区域品红
- 验收：画面有冷/暖对比，不再整屏蓝

## V04 法师剪影

- [ ] 拉长身体比例（scaleY 1.08-1.15）
- [ ] 增加披风/肩甲/法杖挂点
- [ ] 帽檐略收窄，避免“蘑菇”剪影
- 验收：30m 外能看出“法师”，不是蓝色蛋

## V05 星蚀守卫

- [ ] 体量放大 5-10%
- [ ] 品红核心更明显
- [ ] 攻击起手有 0.4s 预警动作
- 验收：30m 外能识别敌人位置和攻击意图

## V06 近景遮挡

- [ ] 减少玩家出生点前方 10m 内的高柱
- [ ] 保持中景地标，不挡准星
- 验收：出生第一眼能看到敌方目标和中央星门

# P2：Combat 2.0（玩法纵深）

## G01 技能组

- [ ] 被动：星辉印记（技能叠层，普攻/技能引爆）
- [ ] Q：可蓄力星弧飞弹
- [ ] W：引力法阵（延迟牵引 + 爆炸）
- [ ] E：折跃（位移 + 短暂无敌帧）
- [ ] R：天穹裂隙（引导扫射）
- 验收：至少 3 套可练连招；每个技能有明确用途

## G02 敌人类型

- [ ] 石卫：慢速重击，起手明显
- [ ] 星蚀术士：远程法球 + 短传送
- [ ] 猎星者：突进背刺，血少
- [ ] 试炼守卫：Boss，护盾阶段 + 环形激光
- 验收：每种敌人有“预警 → 可躲 → 输出窗口”

## G03 战斗反馈

- [ ] 命中停顿 40-70ms
- [ ] 受击闪白/闪红 + 硬直
- [ ] 屏幕震动可调，默认低
- [ ] 低血心跳/边缘红晕
- [ ] 伤害数字分层
- 验收：闭眼听声音也能判断“打中了/被打中了”

## G04 试炼波次

- [ ] 5 波敌人，组合逐波升级
- [ ] 波间 3 选 1 强化
- [ ] 10 分钟内可完成
- 验收：完整打一局不觉得单调

## G05 难度

- [ ] 简单/普通/困难
- [ ] 只调反应、瞄准误差、躲技能概率，不调隐藏数值
- 验收：三档体感明显不同

## G06 教程

- [ ] 3 步提示：移动/技能/推塔
- [ ] 训练场可随时重开
- 验收：新玩家 60 秒内知道怎么打

# P3：中路对决（LoL 骨架）

## L01 小兵

- [ ] 30 秒一波，3 近战 + 1 远程
- [ ] 沿路点推进，攻击仇恨目标
- [ ] 最后一击给金币，附近给经验
- 验收：兵线能自然交汇/推进

## L02 防御塔

- [ ] 2 塔 + 水晶
- [ ] 塔优先小兵，玩家在塔下攻击英雄时转火
- [ ] 塔被摧毁后停止攻击
- 验收：越塔有风险，推塔有收益

## L03 经济/等级

- [ ] 金币：补刀/击杀/推塔
- [ ] 经验：1-10 级
- [ ] 技能点：Q/W/E 最高 4 级，R 自动升级
- 验收：3/6/9 分钟有明确成长感

## L04 商店

- [ ] 6 件装备，基地购买
- [ ] 推荐出装
- [ ] 出售返还 60%
- 验收：每局能买 3-4 件，出装有选择

## L05 敌方英雄 AI

- [ ] 补刀/换血/撤退/回城/推塔
- [ ] 三档难度
- [ ] 不做全图作弊
- 验收：普通 AI 能赢“完全不操作”的玩家

## L06 胜负

- [ ] 水晶归零结束
- [ ] 胜利/失败结算
- [ ] 一键重开
- 验收：完整 8-12 分钟一局
