## 完成内容

### 正式技能图标

- LMB / Q / F / E / R 五个技能卡改为内联 SVG 图标
- 图标随技能色板显示
- 不依赖外部图片资源，加载稳定

### 音频

- Web Audio 主音量 / 音效音量 / 音乐音量三层增益
- 设置面板新增三个音量滑杆
- 低音环境音乐在 Boss 战循环
- 阶段 2 音乐频率切换
- 原有技能/命中/受击/击杀音效保留

### 键位重绑定

设置面板新增：

- Q 技能键
- F 技能键
- E 技能键
- R 技能键
- 跳跃键

已验证：把跳跃从 `Space` 改为 `C` 后，按 `C` 能正常起跳。

### 命中停顿

- 大伤害命中时短暂冻结模拟（约 45ms）
- 普通命中约 20ms
- 视觉上强化打击感

### 战斗统计

暂停界面和胜利结算显示：

- 造成伤害
- 承受伤害
- 命中次数

### 小地图

- 右上角竞技场小地图
- 青色玩家点
- 红色 Boss 点
- 紫色召唤物点

### UI 修正

- 设置面板最大高度 88vh，可滚动，避免音量/键位项被裁切
- 音量与键位设置继续保存到 `localStorage`

## 已知限制

- 音乐是程序化低频环境音，不是正式配乐
- 按键重绑定只覆盖 Q/F/E/R 和跳跃，移动/视角仍固定
- 战斗统计是累计值，没有逐技能伤害复盘
- 小地图是简化矩形映射，没有地形/墙体
- 命中停顿是短冻结，没有逐武器动画
