# 星辉试炼 · 玩家手册

> 项目位置：`G:\shares\games\fp-moba`  
> 当前版本：Boss Rush v0.8.0a（三 Boss + 中路试炼原型）  
> 平台：Windows 桌面浏览器 Chrome / Edge（键鼠）

---

## 1. 启动游戏

### 最简单：双击启动脚本

进入：

`G:\shares\games\fp-moba`

双击：

`启动游戏.cmd`

脚本会：

1. 检查 `4173` 端口是否已有游戏服务；
2. 没有则启动 Vite；
3. 自动打开默认浏览器。

### 手动启动

```powershell
cd "G:\shares\games\fp-moba"
npm install
npm run dev
```

然后打开：

- 本机：**http://127.0.0.1:4173/**
- 局域网：**http://192.168.0.55:4173/**

> Vite 已配置监听 `0.0.0.0`。如果同一局域网的其他设备打不开，需要在 Windows 防火墙允许 Node.js / TCP 4173 的专用网络入站。

### 生产构建

```powershell
npm run build
npm run preview
```

## 2. 进入游戏

1. 打开页面；
2. 等开始按钮从“正在载入星辉峡谷…”变成可点击；
3. 点击 **“点击进入星辉峡谷”**；
4. 鼠标会被锁定，默认进入 **第三人称**；
5. 按 `V` 可切第一人称。

如果页面是旧版本，按 `Ctrl + F5` 强制刷新。

## 3. 操作

| 按键 | 功能 |
|---|---|
| `W / A / S / D` | 移动 |
| `Space` | 跳跃 |
| 鼠标 | 视角 |
| 鼠标左键 | 普攻（按住连发） |
| `Q` | 星弧飞弹：按住蓄力，松开放射 |
| `F` | 引力法阵：按住显示落点，松开释放 |
| `E` | 折跃：8m 闪现 + 0.24s 无敌帧 |
| `R` | 天穹裂隙：2.5s 引导光束 |
| `V` | 第一 / 第三人称切换 |
| `Esc` | 暂停 / 释放鼠标 |

> `D` 始终是右移，不绑定技能。原 W 技能因为和前进冲突，绑定到 `F`。  
> 开始页或暂停页可以打开「技能说明」查看全部技能。

## 4. 当前玩法目标

当前是 **Boss Rush 三 Boss 流程**：

```text
星蚀守卫 1800 HP
  → 击败
  → 3 选 1 星辉强化
  → 虚空术士 2200 HP
  → 击败
  → 3 选 1 星辉强化
  → 星环巨像 2400 HP
  → 击败
  → 最终结算
```

- 星蚀守卫 50% 血量进入 **第二阶段 · 星环解放**，召唤 2 个星蚀碎片
- 虚空术士 50% 血量进入 **第二阶段 · 虚空回响**，召唤 2 个镜像分身
- 虚空术士会传送、释放追踪法球和紫色虚空区域
- 星环巨像会旋转激光、引力牵引和陨星雨
- 星环巨像 50% 血量进入 **第二阶段 · 星环崩解**
- 玩家死亡后 3 秒复活，当前 Boss 重置
- 击败星环巨像后显示用时、剩余生命、等级、本地最快记录
- 结算页可以点 **“再战一次”** 开始全新一局

### 中路试炼原型

开始页模式选择「中路试炼 · 小兵原型」：

- 每 12 秒生成双方各 3 个小兵
- 小兵会互相交战，也会攻击玩家/推进
- 击杀敌方小兵获得 12 金币 + 20 XP
- 按 `B` 打开星辉商店
- 可购买攻击法典、生命护符、星泉药剂
- 敌方防御塔 500 HP、敌方水晶 1000 HP
- 击破水晶触发 `RUN CLEARED` 结算
- 敌方英雄当前复用 Boss 控制器
- 这是原型：独立英雄 AI 和完整 1v1 仍在开发

### 难度与词缀

开始页可选择难度：

- **简单**：Boss 伤害更低、攻击更慢、预警更长
- **普通**：标准
- **困难**：Boss 伤害更高、攻击更快、预警更短

每局随机一个 Boss 词缀：

- 无词缀
- 狂暴：Boss 伤害 +15%，攻击更频繁
- 护盾：Boss 受到伤害 -15%
- 分裂：阶段 2 额外召唤 1 个单位

结算会显示 Build、得分、难度、词缀和本地最高分。

## 5. F 引力法阵

这是当前最重要的范围技能：

1. **按住 F**：显示青色范围圈、中心十字和光柱；
2. 移动准星：落点实时跟随；
3. 准星对准 Boss：落点优先锁定 Boss 脚下；
4. **松开 F**：法阵落在预览位置，0.55 秒后爆炸；
5. 最大射程 30m，基础半径 5.2m。

强化「引力扩张」可以让半径再 +25%。

## 6. Boss 攻击与躲避

| 攻击 | 预警 | 应对 |
|---|---|---|
| 重拳砸地 | 红色地面圈 | 侧移，或按 `Space` 跳跃 |
| 星蚀冲击波 | 橙色大范围圈 | 跑出范围，或跳跃 |
| 晶核弹幕 | Boss 枪口蓄光 | 横向走位；跳跃不能躲弹幕 |
| 阶段 2 星蚀碎片 | 召唤提示 | 横向走位/绕 Boss |
| 虚空区域 | 紫色地面圈 | 离开范围，或跳跃 |
| 追踪法球 | 紫色光球 | 持续横向移动，不要站桩 |
| 虚空传送 | 紫色闪光 | 立刻转身找 Boss |
| 阶段 2 镜像分身 | 紫色分身 | 优先清分身，避免被夹击 |
| 旋转激光 | 橙色双光束 | 看光束方向，绕到背面/跳过光束 |
| 引力牵引 | 金色脉冲 | 向反方向持续移动 |
| 陨星雨 | 橙色落点圈 | 连续移动，不要停在原地 |

**跳跃只躲地面伤害，不躲弹幕。**  
所有高伤害攻击都有地面预警，看到红/橙/紫圈先移动。

## 7. 等级与强化

### 等级

- 最高 **20 级**
- XP 来源：造成伤害 ×0.4 + 击杀 60
- 每级提升：
  - 最大生命 +8
  - 最大法力 +7
  - 伤害 +4.5%
  - 普攻速度 +2%
  - 冷却缩减 2%
- 升级回复 12 生命并回满法力

### 3 选 1 强化池

- 星弧过载：Q 蓄力速度 +30%
- 引力扩张：F 半径 +25%
- 折跃回响：E 冷却 -20%
- 棱镜增幅：R 伤害 +30%
- 冷却回响：所有技能冷却 -10%
- 星屑护体：最大生命 +25
- 猎星步：普攻速度 +15%
- 星辉烙印：印记引爆伤害 +50%
- 虚空追猎：追踪法球伤害 +25%
- 坍缩边界：虚空区域半径 +20%

强化卡有普通/稀有/史诗三种稀有度，稀有度越高越少见。

联动：

- 星辉连锁：Q 蓄力 + 印记强化同时拥有时，Q 类伤害 +15%
- 奇点扩张：F 范围 + 虚空范围同时拥有时，F 半径额外 +10%

## 8. 舒适设置

开始页或暂停页点击 **“舒适设置”**：

- FOV 60-90（默认 70）
- 默认第一/第三人称
- 鼠标灵敏度
- 武器晃动 0-100%
- 屏幕震动 0-100%
- 画质低/中/高
- 隐藏第一人称武器
- 反转 Y 轴
- 主音量 / 音效音量 / 音乐音量
- Q / F / E / R 技能键重绑定
- 跳跃键重绑定（默认 Space）

设置会保存在浏览器 `localStorage`。如果容易晕 3D，建议：

- 第三人称
- FOV 68-72
- 武器晃动 0%
- 屏幕震动 0%
- 画质中

## 9. 常见问题

### 页面打不开

- 确认服务已启动；
- 本机试 `http://127.0.0.1:4173/`；
- 按 `Ctrl + F5`；
- 检查 4173 端口是否被占用。

### 鼠标没有锁定

点击“继续”或画面重新锁定；如果浏览器拒绝，换 Chrome / Edge 再试。

### 没有声音

浏览器要求用户交互后才允许音频；进入游戏、点击画面后才会播放。

### 觉得晕

优先使用第三人称，打开舒适设置把 FOV 调到 70、武器晃动 0、屏幕震动 0。
