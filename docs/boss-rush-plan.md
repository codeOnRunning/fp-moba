# Boss Rush / Roguelike 第一版方案

> 已选路线：**Boss Rush / Roguelike**  
> 当前基础：Art Pass 1.0 场景 + 第三人称舒适模式 + Q/普攻 + 星蚀守卫  
> 目标：先做一个 **5-8 分钟、有 1 个 Boss、4 个技能、死亡重试、本地计时** 的可玩版本，再逐步扩到 3 Boss + 强化选择。  
> 进度：**v0.2.2a 已完成**（Q/F/E/R + 被动、跳跃、三轮星蚀守卫、3 选 1、竞技场、计时、死亡重试、结算），见 [`../BOSS-RUSH-STATUS.md`](../BOSS-RUSH-STATUS.md)。

## 1. 第一版做什么

### v0.2.1：Boss Rush 核心（4-6 天）

- 玩家：Q/F/E/R + 被动（W 与移动冲突，引力法阵绑定 F）
- Boss：星蚀守卫（1 个，2 个阶段）
- 场景：复用当前星辉峡谷，围出 Boss 竞技场
- 流程：进入 → Boss 战 → 胜利结算 / 死亡重试
- UI：Boss 血条、阶段、计时、技能冷却
- 本地记录：最快通关时间
- 不做：小兵、塔、商店、第二/第三个 Boss（下一版）

### v0.2.2：3 Boss + 3 选 1（5-7 天）

- Boss 2：虚空术士
- Boss 3：星环巨像
- 每个 Boss 后 3 选 1 强化
- 难度选择
- 本地最高分/最快时间

### v0.2.3：Roguelike 化（5-7 天）

- 随机词缀/事件
- 更多强化组合
- 无尽模式/每日挑战
- 结算统计与分享

## 2. 玩家技能组

| 技能 | 设计 | 作用 |
|---|---|---|
| **被动：星辉印记** | 技能命中叠 1 层，3 层后下一次普攻引爆额外伤害 | 鼓励技能 + 普攻交替 |
| **Q：星弧飞弹** | 可蓄力 0.6s，蓄力越久伤害/速度越高；贯穿小兵，命中 Boss 停止 | 主力远程输出 |
| **F：引力法阵** | 准星落点生成 4m 法阵，1s 后牵引 + 爆炸（W 与移动冲突，绑定 F） | 封走位/打爆发 |
| **E：折跃** | 8m 闪现，0.2s 无敌帧，留下残影 | 躲 Boss 技能 |
| **R：天穹裂隙** | 2.5s 引导光束，可缓慢扫射；引导时移速 -30% | 高风险高回报 |

### 等级成长（第一版 20 级）

- 伤害、攻速、冷却缩减、最大生命/法力随等级提升。
- 傀儡每次复活最大生命 +60，上限 1800。
- 后续可在 Boss Rush 中把等级重置为每局成长，或保留为局外成长。

### 连招示例

- F 封路 → Q 蓄力 → E 调整角度 → R 扫射
- 技能叠 3 层印记 → 普攻引爆 → Q 收尾
- Boss 起手 → E 穿过 → 反手 F + Q

## 3. Boss 1：星蚀守卫

### 基础

| 项目 | 数值（初稿） |
|---|---|
| 生命 | 1800 |
| 阶段 | 100%-50% / 50%-0% |
| 移动 | 缓慢追击，不离开 arena |
| 弱点 | 背后核心，受到伤害 +20% |
| 奖励 | 通关时间 + 评分 |

### 攻击模式

| 攻击 | 预警 | 效果 | 应对 |
|---|---|---|---|
| **重拳砸地** | 0.8s 红圈 | 4m 范围高伤害 | 侧移/E 躲 |
| **星蚀冲击波** | 1.0s 环形预警 | 向外扩散的环，命中击退 | 贴近或远离环 |
| **晶核弹幕** | 0.5s 枪口发光 | 3 发扇形弹 | 横向走位 |
| **阶段 2：星环激光** | 1.2s 旋转预警 | 围绕 Boss 的环形激光 | 找缺口/E 穿 |
| **阶段 2：召唤** | 0.8s 地面符文 | 召唤 2 个猎星者 | 优先清小怪 |

### 阶段转换

- 50% 血量：Boss 短暂无敌 1.5s，播放护盾破裂，进入阶段 2。
- 阶段 2：攻击速度 +20%，新增星环激光/召唤。

## 4. 一局流程

```text
主菜单/难度
  → 进入星辉竞技场
  → Boss 登场（1.5s 演出）
  → 战斗（3-5 分钟）
  → 胜利：结算时间/评分/最快记录
  → 或死亡：3 秒倒计时 → 重试当前 Boss
```

### 死亡与重试

- 第一版：**重试当前 Boss**，Boss 血量重置，玩家满血，计时继续（方便调试）。
- 正式版：死亡重开整轮，或加时间惩罚；等测试后再定。

### 计时/评分

- 计时从 Boss 登场开始。
- 评分：通关时间 + 无伤/剩余血量 + 连击/印记引爆次数。
- 本地保存最快时间（`localStorage`）。

## 5. 场景与镜头

- 复用当前星辉峡谷中央区域。
- 在 x=-18 到 x=18、z=-12 到 z=12 围出 Boss 竞技场：
  - 用现有石墙/雾门/光墙做边界；
  - 玩家不能跑出 arena；
  - 保持第三人称默认、FOV 70、舒适设置。
- Boss 始终面向玩家，攻击预警圈在地面清晰可见。
- 屏幕边缘显示 Boss 方向指示器（如果被柱子遮挡）。

## 6. UI

### 战斗 HUD

- 顶部中央：Boss 名称 + 大血条 + 阶段标记
- 左上：计时
- 左下：玩家生命/法力
- 底部中央：Q/F/E/R 冷却
- 右上：难度/评分
- 死亡：重试按钮 + 本次伤害统计

### 结算

- 通关时间
- 剩余生命
- 最高连击/印记引爆次数
- 最快记录
- “再战一次” / “返回主菜单”

## 7. 技术实现

### 新增模块

```text
src/game/boss/
  BossController.ts      Boss 状态机、阶段、攻击选择
  BossAttacks.ts         重拳/冲击波/弹幕/激光/召唤
  BossArena.ts           竞技场边界与预警
  RunManager.ts          计时、死亡、重试、结算
src/game/abilities/
  AbilitySystem.ts       Q/F/E/R 冷却、法力、施法
  GravityZone.ts         F 引力法阵
  BeamAbility.ts         R 光束
```

### 复用

- `CharacterView`：Boss 用 Skeleton Warrior 放大 1.5-1.8 倍 + 品红核心
- `ProjectileSystem`：Boss 弹幕
- `Effects`：预警圈、命中、阶段转换
- `Hud`：Boss 血条、冷却、结算
- `SettingsStore`：舒适设置保持不变

```ts
interface BossAttack {

interface RunState {
  bossIndex: number;
  startedAt: number;
  deaths: number;
  bestTime: number | null;
}
```

## 9. 验收标准

- [ ] Q/F/E/R + 被动全部可用
- [ ] 至少 3 套连招
- [ ] Boss 有 4 种攻击 + 2 阶段
- [ ] 所有高伤害攻击都有 0.8s 以上预警
- [ ] 一局 3-5 分钟
- [ ] 死亡能 3 秒内重试
- [ ] 本地最快时间保存
- [ ] 第三人称 15 分钟不晕
- [ ] 目标设备 60 FPS
- [ ] 控制台 0 error

## 10. 风险

| 风险 | 应对 |
|---|---|
| 4 个技能同时做太大 | 先做 Q/F/E，R 后置一天 |
| Boss 攻击看不清 | 所有攻击先做地面预警，再加特效 |
| 第三人称瞄准难 | 准星 + Boss 弱点高亮 + 弹道辅助 |
| 玩家风筝导致战斗拖长 | Boss 远程弹幕/冲刺，限制 arena |
| 数值太难/太简单 | 先调 Boss 血量/攻击频率，不调玩家伤害 |
| 美术/特效拖时间 | 先用现有模型放大 + 颜色/粒子，不做新模型 |
