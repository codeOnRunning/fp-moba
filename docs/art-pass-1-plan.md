## 1. 本阶段到底做什么

### 做

1. **场景重建**：同一张中路地图，改成三个视觉分区 + 6 个地标。
2. **角色替换**：玩家法师、训练傀儡换成有剪影、有配色、有动画的低模。
3. **灯光/天空/后处理**：深靛夜空、月金主光、星青补光、品红敌辉、轻量 Bloom。
4. **VFX**：Q、普攻、敌方弹道、命中、死亡、拾取/升级（预留）。
5. **UI 美术**：技能图标、目标框、冷却扇形、伤害数字、准星。
6. **音频氛围**：环境底噪、脚步、施法、命中、低血心跳。
7. **性能与 QA**：60 FPS、draw call 预算、截图验收。

### 不做

- 不加 W/E/R；
- 不加小兵、塔、商店；
- 不改移动速度、伤害、冷却；
- 不做 5v5、多人、移动端；
- 不做写实 3A 资产。

> 这一阶段是“换皮 + 换镜头语言”，不是“换游戏”。

- 玩家：星青 `#57E0F0` + 月金 `#E8C77A`

## 4. 场景结构

### 4.1 保持现有碰撞布局

当前 `map.ts` 的碰撞/出生点/塔位先不改，只替换视觉：

```text
玩家出生 -20m
蓝方外塔 -45m
蓝方内塔 -80m
中路中心 0m
红方外塔 +45m
红方内塔 +80m
水晶 ±110m
```

这样可以保证：

- 移动距离不变；
- 假人 AI 射程不变；
- 后续 M1 加小兵/塔时不用重做地图；
- 美术升级不会破坏 M0 手感。

### 4.2 场景模块清单

| 模块 | 数量 | 说明 |
|---|---|---|
| 地面石板 | 80-120 | 4m 网格，破损/完整混用 |
| 墙体/矮墙 | 30-40 | 两侧边界，避免平墙 |
| 拱门 | 6-8 | 每 20-30m 一个地标 |
| 柱子 | 10-14 | 断裂/完整/星盘柱 |
| 悬浮水晶 | 6-8 | 青/紫/品红，发光 |
| 旗帜 | 6 | 蓝方/红方 |
| 火盆/灯笼 | 10-12 | 暖光点 |
| 废墟/碎石 | 20-30 | 打破地面重复 |
| 星环/星盘 | 2-3 | 远景/中央地标 |
| 天空 | 1 | 渐变天幕 + 星环 + 远山 |

### 4.3 构图原则

- 第一人称视线沿 -X/+X 方向看，主地标必须落在视线中心附近；
- 每 20-30m 有一个“高对比剪影”，避免纯平墙；
- 地面用虚线/砖缝/符文引导路线；
- 画面左右不能完全对称，加入破损和倾斜；
- 远处用雾和巨大星环制造纵深；
- 敌人区域用品红光源，玩家区域用青色光源。

## 6. 灯光、天空、后处理

### 6.1 灯光

| 灯光 | 颜色 | 作用 |
|---|---|---|
| 主光 Directional | 月金 `#FFE2B0` | 打出建筑边缘和角色轮廓 |
| 补光 Hemisphere | 星青 `#8ECFFF` | 压暗部，保持冷色 |
| 敌方点光 | 品红 `#FF5C8A` | 红方区域和敌人核心 |
| 玩家点光 | 星青 `#57E0F0` | 出生点/法杖 |
| 火光点光 | 暖橙 `#FF9A5C` | 火盆/灯笼，增加温度 |

### 6.2 天空

- 渐变天幕：深靛 → 夜蓝 → 地平线微亮；
- 巨大星环：金色椭圆环 + 青色外环；
- 远山剪影：2-3 层，低对比；
- 星尘粒子：少量、慢速、只在远景；
- 不用真实 HDRI，保持风格化和性能。

### 6.3 后处理

- `EffectComposer` + `RenderPass`；
- 轻量 Bloom（只让自发光溢出）；
- 暗角（Vignette）；
- 色调映射（ACES）；
- 可选颗粒/色差，默认关闭；
- 画质档位：低/中/高，低配关闭 Bloom。

### 6.4 性能预算

| 项目 | 目标 |
|---|---|
| FPS | 60（1080p 中端 GPU） |
| Draw calls | < 250 |
| 三角形 | < 1.5M |
| 动态光源 | 1 主光 + 3 点光 + 环境 |
| 阴影 | 1 个方向光阴影；小物件 blob shadow |
| 纹理 | 1024/2048 图集，KTX2/Basis |
| 初始包体 | < 25MB（压缩后） |
| 加载 | < 15s |

## 8. 技术实现

### 8.1 新目录

```text
public/assets/
  env/                 GLB 场景模块
  characters/          玩家/敌人 GLB
  textures/            KTX2/PNG
  audio/               OGG
src/game/art/
  AssetLoader.ts       GLTFLoader + DRACOLoader + KTX2Loader
  EnvironmentBuilder.ts 模块化场景拼装
  CharacterFactory.ts  角色加载、换色、装备挂点
  Lighting.ts          灯光/天空/雾
  PostFx.ts            Bloom/暗角/色调
  Vfx.ts               技能/命中/死亡特效
```

### 8.2 加载策略

- 首屏只加载：玩家、傀儡、地面、关键地标；
- 背景/远景/装饰延迟加载；
- 失败降级：模型加载失败时回退到当前灰盒几何体；
- `LoadingManager` 显示进度；
- 所有 GLB 走 `DRACOLoader`；纹理走 `KTX2Loader`。

### 8.3 场景拼装

- 用 4m 网格拼地面/墙；
- 重复件用 `InstancedMesh`；
- 静态件按材质合并 `mergeGeometries`；
- 碰撞仍用简单 box/cylinder，不跟渲染网格走；
- 灯光/雾/天空用单独 `Lighting` 模块；
- 保留 `map.ts` 的碰撞/出生点，新增 `EnvironmentBuilder` 只做视觉。

### 8.4 角色

- `GLTFLoader` 加载；
- `SkeletonUtils.clone` 克隆骨骼；
- `AnimationMixer` 管理 idle/walk/cast/hit/death；
- 材质换色：遍历 mesh，替换/调整 `MeshStandardMaterial` 颜色；
- 武器挂点：`staff` bone 或手部空节点；
- 第一人称 viewmodel 与第三人称身体分开，避免穿模。

## 11. 风险与应对

| 风险 | 应对 |
|---|---|
| 不同 CC0 包风格不统一 | 先做 Look Dev，只选 2 个主包；统一调色/材质 |
| 资产缩放/轴向不一致 | 统一 1 unit = 1m；导入时检查 forward/up |
| 角色动画不匹配 | 先用 KayKit 同源动画；不匹配就程序化动作 |
| 后处理拖帧 | Bloom 降分辨率/半分辨率；低配关闭 |
| 场景 overdraw | 控制透明粒子/雾；限制光源 |
| 角色定制被卡住 | 先“CC0 骨架 + 换色/换武器”，全定制后置 |
| 美术做完玩法又改 | 保持碰撞/布局不变；只换视觉层 |
| 包体过大 | GLB Draco + KTX2；按需加载；首屏只加载必要资产 |

## 12. 本阶段结束后的下一步

Art Pass 1.0 完成后，进入 **Combat 2.0**：

- W/E/R + 被动；
- 3 种敌人 + 5 波；
- 命中停顿/预警/连招；
- 3 选 1 强化。

然后再进入 **v0.3 中路对决**（小兵/塔/水晶/商店/AI）。

这样顺序的好处：

1. 先让画面“拿得出手”，你有继续做的动力；
2. 角色/场景资产在 Combat 2.0 中直接复用；
3. 玩法系统不会因为美术返工而重做。
