# P8 验收记录 · 角色美术打磨

> 日期：2026-11-19  
> 版本：v0.9.0a（Art Pass 2.0 第一轮）  
> 测试环境：Chrome + NVIDIA GeForce RTX 3050  
> 截图：[Boss Rush 角色](./art-boss.png)、[中路试炼角色与小兵](./art-lane.png)

## 问题

- 中路小兵是胶囊体 + 球头 + 刀片，和 KayKit 角色完全不是一个美术层级
- 玩家只有原始 KayKit 法师，缺少武器和英雄辨识度
- 敌方英雄只有原始骷髅模型，远看像杂兵
- 战斗场景里双方角色轮廓和队伍颜色不够清楚

## 本轮改动

### 小兵

- 删除胶囊体小兵
- 玩家小兵使用 KayKit Mage 模型
- 敌方小兵使用 KayKit Skeleton Warrior 模型
- 双方小兵带行走/待机/受击动画
- 玩家小兵青色染色，敌方小兵红色染色
- 保留血量和碰撞体积

### 玩家英雄

- 增加深蓝肩甲/披肩
- 增加金色法杖
- 法杖带青色星辉晶体和光环
- 增加脚下青色星辉环
- 保留原有法师模型和动画，避免破坏操作手感

### 敌方英雄

- 模型缩放提升：星蚀 1.5 / 虚空 1.42 / 星环 1.95
- 增加黑金尖刺冠
- 增加胸甲核心
- 增加肩甲
- 增加破碎大剑
- 增加对应 Boss 颜色的脚下光环
- 星蚀 / 虚空 / 星环三种颜色区分
- 新增动作：登场复活、行走、战斗待机、重拳、旋转冲击、远程射击、阶段嘲讽、召唤
- 动作使用 KayKit 原生骨骼动画，不额外增加贴图

## 已知限制

- 角色仍是 KayKit 模块化资产，不是全定制建模
- 小兵模型增加后 draw calls 明显上升，后续需要合并/实例化
- 玩家法杖是附加装饰，不是手部骨骼绑定，攻击动作时不会跟手
- 敌方大剑/冠饰是程序化附加物，近看仍能看出拼接
- 尚未替换场景中的塔/水晶模型
