# 难度模式设计（2026-11-26）

> 目标：让第一次接触的玩家也能打通 Boss Rush，同时给熟练玩家保留挑战空间。

## 五档难度

| 难度 | Boss 生命 | Boss 伤害 | 攻击间隔 | 预警时间 | 弹速 | 玩家生命 | 玩家伤害 | 分数加成 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 剧情 | ×0.55 | ×0.45 | ×1.35 | ×1.50 | ×0.65 | ×1.30 | ×1.20 | 0 |
| 简单 | ×0.80 | ×0.70 | ×1.20 | ×1.25 | ×0.85 | ×1.10 | ×1.05 | 0 |
| 普通 | ×1.00 | ×1.00 | ×1.00 | ×1.00 | ×1.00 | ×1.00 | ×1.00 | 3000 |
| 困难 | ×1.15 | ×1.25 | ×0.86 | ×0.82 | ×1.15 | ×0.95 | ×0.95 | 8000 |
| 噩梦 | ×1.30 | ×1.50 | ×0.72 | ×0.68 | ×1.30 | ×0.85 | ×0.90 | 15000 |

## 可访问性设计

- **剧情难度清空随机词缀**：Boss 必定无词缀，避免新玩家同时面对难度和随机惩罚。
- **暂停菜单可改难度**：无需退出本局；Boss 当前血量百分比保留，切换不会重置战斗。
- **死亡界面一键降档**：被击倒后可以直接选择降一档并复活，而不是反复卡在同一个 Boss。
- **玩家数值随难度调整**：不只是敌人变弱，玩家最大生命与伤害也会随难度变化，让「剧情」明显更宽容。

## 代码位置

- `src/game/RunModifiers.ts`：难度配置、难度顺序、词缀抽取
- `src/game/Game.ts`：Boss 生命/伤害、玩家生命/伤害、暂停与死亡界面难度切换
- `index.html`：开始页难度选项、暂停难度选择、死亡界面降档按钮
- `src/style.css`：难度提示与暂停/死亡界面样式

## 验收

- 开始页显示 5 档难度并有实时说明
- 选择剧情后首个 Boss 生命为 `1800 × 0.55 = 990`
- 暂停中切换难度后 Boss 血量保持相同百分比
- 死亡界面「降低难度并复活」可用，最低难度时置灰
- `npm run typecheck` 与 `npm run build` 通过
- `node scripts/difficulty-test.mjs` 通过（需先运行 `npm run dev`，默认测试 `http://127.0.0.1:5173/`）
