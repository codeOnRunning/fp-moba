## 改动

### 通用特效

- `Effects` 新增可扩散的 **Additive 地面光环**
- `Effects` 新增 **六边形符文**
- 命中现在同时有闪光、粒子爆发和扩散环
- 施法脉冲增加环形冲击

### 玩家技能

- Q：法杖端部施法闪光 + 扩散环
- Q/E/敌方飞弹：加入拖尾 sprite
- W：爆炸时生成青色六边形引力符文
- E：折跃起点产生扩散环
- R：落点生成大型青色符文 + 施法脉冲

### Boss

- 重拳/冲击波/虚空落点：命中时额外产生扩散环
- 阶段转换：Boss 脚下生成 Boss 色符文
- 引力牵引：金色符文
- 旋转激光：金色核心符文
- 陨星雨：每个落点命中增加冲击环

## 性能

- Boss Rush：**60 FPS / 238 draw calls / 210k tris**
- Q/R/F 连续施放：0 console error
- `npm run typecheck`：通过
- `npm run build`：通过

## 已知限制

- 特效以 Additive sprite / ring 为主，没有自定义 shader
- 大量粒子叠加时 draw calls 会上升
- 特效音画同步仍是程序化音效
- 没有做屏幕空间 bloom 的后处理调参
