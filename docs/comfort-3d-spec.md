# 第一人称 3D 晕动症专项规格（P0）

> 项目：`fp-moba/`  
> 目标：在不改变 M0 核心玩法的前提下，把“移动/转视角就晕”的概率显著降低。  
> 优先级：**最高。舒适度问题解决前，不继续大规模堆场景和玩法。**

---

## 1. 先判断：当前为什么会晕

结合当前实现，最可能的五个原因按优先级排列：

| 优先级 | 原因 | 当前实现 | 为什么会晕 | 处理方向 |
|---|---|---|---|---|
| P0 | **垂直 FOV 过大** | `PerspectiveCamera(80, ...)`，80° 是垂直 FOV | 16:9 下水平 FOV 约 105°，边缘拉伸明显；转头时周边画面流动过快 | 默认降到 70-72°，提供 60-90° 滑杆 |
| P0 | **移动没有加速/减速** | `PlayerController` 直接以 6.5 m/s 移动，松键瞬停 | 起步/停止过于生硬，视觉前庭系统受到突变 | 加速度 18-22 m/s²，减速度 24-30 m/s²，最高速度 5.2-5.8 m/s |
| P0 | **相机完全硬跟随** | 相机每秒直接复制角色位置，没有高度稳定 | 地面/碰撞微小变化会传到镜头，产生细碎抖动 | 只对相机 Y 做 18-24 阻尼；水平位置保持直接，避免输入延迟 |
| P1 | **第一人称武器晃动** | `updateViewmodel` 有 8.5 rad/s 的 bob | 视野边缘持续摆动，容易诱发晕动 | 默认关闭 bob；提供 0-100% 滑杆；保留轻微施法后坐 |
| P1 | **第三人称相机没有平滑** | 直接 `lookAt`，碰撞时位置突变 | 第三人称切换/贴墙时镜头跳变 | 弹簧臂位置阻尼 + 碰撞安全距离 + 不做瞬间拉近 |
| P1 | **帧率不稳定 / Bloom 成本** | 场景加载 12MB 模型，Bloom + 阴影 | 低帧率/帧时间波动比平均 FPS 更容易致晕 | 增加画质档位、动态分辨率、Bloom 可关、稳定 60 |
| P2 | **场景近处遮挡多** | 星门、柱廊、侧墙较近 | 近处物体快速掠过，周边视差大 | 构图第二版：缩小星门、减少近景柱、扩大中景视野 |
| P2 | **镜头震动/受击反馈** | 目前轻微，但后续会加 | 震动和 roll 是晕动症高发因素 | 默认低强度；提供关闭；永不自动加 roll |

> 结论：**先改 FOV + 移动曲线 + 相机高度稳定 + 关闭武器 bob + 稳定帧率**，这五项是最高性价比。

---

## 2. 必须实现的舒适设置

### 2.1 相机

- [ ] 默认垂直 FOV：**70°**（可调 60-90°，步进 1°）
- [ ] 不做冲刺 FOV 变化、不做受击 FOV 变化
- [ ] 相机 roll 永远为 0（不随移动/转向倾斜）
- [ ] 默认无头部晃动（head bob）
- [ ] 默认无动态模糊、景深
- [ ] 受击屏幕震动默认 **低**，可关闭；强度 0-100%
- [ ] 相机高度稳定：
  - 水平位置直接跟随角色；
  - Y 轴使用 `MathUtils.damp`，lambda 18-24；
  - 不把物理碰撞的微小 Y 抖动传给镜头。
- [ ] 第三人称相机：
  - 弹簧臂平滑；
  - 遇到墙体时拉近但不瞬移；
  - 默认距离 4.5m，可调 3.5-6m；
  - 不在第三人称下播放第一人称武器 bob。

### 2.2 移动

- [ ] 最高速度从 6.5 m/s 降到 **5.5 m/s**（先测试，必要时 5.2）
- [ ] 起步加速：18-22 m/s²
- [ ] 松键减速：24-30 m/s²
- [ ] 斜向移动归一化，不能比直线更快
- [ ] 不做“瞬间转身”；角色朝向跟随相机 yaw，但相机旋转保持原始鼠标输入，不做过度平滑
- [ ] 后退速度略低于前进（可选 0.8 倍）
- [ ] 不做自动冲刺、不做速度线、不做边缘模糊

### 2.3 武器/第一人称 viewmodel

- [ ] 默认关闭行走 bob（设为 0%）
- [ ] 提供 `武器晃动` 滑杆：0-100%
- [ ] 施法后坐幅度降低 30-50%
- [ ] 提供 `隐藏武器` 开关
- [ ] viewmodel 不参与相机旋转，不改变准星位置

### 2.4 画面稳定性

- [ ] 固定 60Hz 模拟 + 渲染插值；避免物理步进和渲染帧率耦合
- [ ] 帧时间稳定优先于平均 FPS：
  - 连续 3 秒低于 55 FPS 时自动降画质；
  - 低画质：关闭 Bloom、降低阴影分辨率、限制像素比 1.25；
- [ ] 不出现加载中卡顿：资产加载完成前禁用开始按钮（已实现）
- [ ] 静态暗角（vignette）可开关；默认开启轻度暗角，减少周边运动感知
- [ ] Bloom 可关闭；默认中低强度
- [ ] 准星固定屏幕中心，不随呼吸/走动漂移

### 2.5 控制

- [ ] 鼠标灵敏度 0.5-2.0 倍滑杆，默认 1.0
- [ ] 关闭鼠标加速（使用 Pointer Lock 原始 movement）
- [ ] 提供反转 Y 轴
- [ ] 提供 `视角平滑` 0-0.25 秒滑杆，默认 **0**（平滑会增加输入延迟，默认不做）
- [ ] `Esc` 暂停后重新进入，不重置视角/位置

## 3. 舒适模式（一键预设）

在设置中增加 **“舒适模式”** 开关，默认开启：

开启后：

- FOV 70°
- 武器 bob 0%
- 屏幕震动 0%
- Bloom 关闭或最低
- 静态暗角开启
- 第三人称相机平滑
- 不改变移动速度/伤害/技能

关闭后：恢复当前“沉浸模式”参数，但所有参数仍可单独调。

## 4. 设置面板 UI

新增 `设置`（暂停菜单 / 开始界面均可进入）：

```text
[画面]
  画质：低 / 中 / 高
  FOV：60 - 90（默认 70）
  Bloom：开 / 关
  暗角：开 / 关
  帧率上限：60 / 120 / 不限制

[舒适度]
  舒适模式：开 / 关
  武器晃动：0 - 100%
  屏幕震动：0 - 100%
  视角平滑：0 - 0.25s
  隐藏武器：开 / 关

[控制]
  鼠标灵敏度：0.5 - 2.0
  反转 Y 轴：开 / 关
  按键绑定（后续）

[音频]
  主音量 / 音乐 / 音效
```

所有设置写入 `localStorage`，刷新后保留。

## 5. 测试方法（必须做，不然只是猜）

### 5.1 测试对象

- 3-5 人，至少 1 人平时容易晕 3D；
- 使用同一台目标设备、Chrome/Edge；
- 测试前不使用其他第一人称游戏。

### 5.2 测试流程（每人 15 分钟）

1. 2 分钟：直线行走 + 停止；
2. 2 分钟：左右横移 + 转视角；
3. 2 分钟：连续转向 180°、抬头/低头；
4. 5 分钟：正常战斗（Q/普攻/移动/受击）；
5. 4 分钟：自由探索/第三人称切换；
6. 记录：是否头晕、恶心、眼疲劳、方向感丢失。

### 5.4 验收标准

- [ ] 5 人中至少 4 人完成 15 分钟无明显恶心；
- [ ] 平均舒适度 ≥ 4/5；
- [ ] 没有“转视角就晕”的集中反馈；
- [ ] 帧时间稳定，无明显掉帧/卡顿；
- [ ] 如果仍有人晕，默认改为第三人称，第一人称作为可选模式。

## 7. 止损线

如果完成 P0 后仍有明显晕动：

1. 第一人称默认改为**第三人称**；
2. 移动速度降到 5.0，FOV 收到 65；
3. 关闭 Bloom/暗角/所有镜头震动；
4. 仍然不行，则把产品定位改为“第三人称动作 MOBA”，第一人称只作为演出/瞄准模式。

> 不要用“再习惯一下”来掩盖晕动症；这是产品体验问题，不是玩家的问题。

---

## 8. 结论

晕 3D 的优先级高于继续加场景和技能。  
**先做 P0 舒适度基线（2-3 天），找 3-5 人实测；通过后再回到美术构图和玩法。**
