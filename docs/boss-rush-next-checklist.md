# Boss Rush 下一阶段清单

> 当前状态：v0.2.2a 已可玩（3 选 1 + 三轮轮回）  
> 已有：Q/F/E/R + 被动、跳跃、等级 1-20、星蚀守卫 1800 HP / 2 阶段、竞技场、计时、死亡重试、胜利结算、F 落点预览。  
> 当前最大问题：**只有 1 个 Boss、没有局内 Build 选择，打几局就会重复。**

---

## 优先级总览

| 优先级 | 目标 | 预计 | 说明 |
|---|---|---|---|
| **P0** | Boss 战斗可读性 + 数值调优 | 2-3 天 | 先让现有 Boss 战“好看、好躲、有节奏” |
| **P1** | 3 选 1 强化 + 第二个 Boss | 5-7 天 | 真正形成 Roguelike 循环 |
| **P2** | 第三个 Boss + 难度/词缀 | 5-7 天 | 完整 Boss Rush |
| **P3** | VFX/音频/UI/性能 | 3-5 天 | 提升完成度 |
| **P4** | 小兵/塔/商店/中路 | 10-14 天 | 回到 LoL 骨架，后置 |

- [ ] 重拳：红圈 + 地面裂纹

- [ ] 阶段 2 碎片：召唤预警圈
- [ ] 所有高伤害攻击预警 ≥0.8s

- [ ] 弹幕速度/密度

- [ ] 技能冷却完成提示音

## B06 信息

- [ ] 技能说明面板（按 Tab 或暂停查看）

- [ ] 跳跃说明：只躲地面伤害
- [ ] 结算显示“为什么失败/哪里可以提升”

# P1：3 选 1 + 第二个 Boss（5-7 天）

## R01 局内强化

每个 Boss 击败后出现 3 选 1：

- [ ] 星辉过载：Q 蓄力速度 +30%
- [ ] 引力井：F 半径 +25%
- [ ] 折跃余波：E 落点小范围伤害
- [ ] 星屑护体：击杀获得临时护盾
- [ ] 棱镜折射：R 引导产生折射弹
- [ ] 冷却回响：技能命中减少其他技能冷却
- [ ] 星辉烙印：印记上限 +1，引爆伤害 +50%
- [ ] 猎星步：移动速度 +10%，E 冷却 -20%

要求：

- [ ] 每局至少 3 次选择
- [ ] 同一强化可叠加/有上限
- [ ] 选择后立即生效
- [ ] 结算展示本局 Build

## B07 第二 Boss：虚空术士

- [ ] 生命 1500 / 2 阶段
- [ ] 传送：短距离闪烁
- [ ] 追踪法球：慢速追踪，可打掉
- [ ] 虚空区域：地面持续伤害
- [ ] 镜像：召唤 2 个低血量分身
- [ ] 阶段 2：法球数量 +1、传送更频繁

## R02 两 Boss 流程

```text
Boss 1 星蚀守卫
  → 3 选 1
  → Boss 2 虚空术士
  → 结算
```

- [ ] 8-10 分钟一局
- [ ] 死亡重试当前 Boss
- [ ] 本地最快通关时间
- [ ] 失败统计
