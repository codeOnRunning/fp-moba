# 第一人称单机 MOBA：MVP 执行方案 v0.1

> 关联调研：`docs/web-fp-moba-research.md`  
> 已锁定：1v1 中路 / 远程法术 / 第一人称 + 第三人称切换 / Three.js + TypeScript + Rapier  
> 目标：先做一个 **8-12 分钟、能完整胜负、手感成立** 的单机垂直切片，不追求内容量。  
> 实施状态（2026-11-13）：**M0 已完成**，可运行代码在 `fp-moba/`，验收记录见 `fp-moba/M0-ACCEPTANCE.md`。

---

## 1. 产品定义

### 1.1 一句话

> 一款浏览器里的第一人称单机“中路对决”：你操控一名原创法师，在简化兵线上补兵、升级、买装备，击败敌方 AI 英雄并推掉两座塔，最终摧毁敌方水晶。

### 1.2 目标玩家

- 玩过 LoL / Dota，想体验“亲自站在峡谷里”的感觉；
- 喜欢 3D 动作战斗，但不想打多人排位；
- 能接受 10 分钟一局、低多边形美术、单机 AI。

### 1.3 成功标准（MVP）

| 维度 | 达标线 |
|---|---|
| 核心手感 | 第一人称移动、瞄准、施法不别扭；连续玩 3 局不眩晕 |
| 完整对局 | 能从开局打到水晶爆炸，失败也能正常重开 |
| 时长 | 8-12 分钟一局，最长不超过 15 分钟 |
| AI | 普通难度能补刀、换血、撤退、回城、推塔；不是木桩 |
| 性能 | 目标设备 1080p 稳定 60 FPS；加载 < 15 秒 |
| 稳定性 | 连续 30 分钟无崩溃、无卡死、无控制台报错 |
| 内容 | 1 张地图、1 个英雄、4 个主动技能、6-8 件装备、3 档难度 |

### 1.4 明确不做（MVP 阶段）

- 不做多人、匹配、排位、好友、服务器；
- 不做野区、打野、河道、Buff、插眼、迷雾；
- 不做 5v5、AI 队友、兵线分路；
- 不做符文、天赋、召唤师技能树、皮肤、剧情；
- 不做移动端、手柄、VR；
- 不使用 LoL 的英雄名、模型、图标、音效、地图素材。

## 2. 一局怎么玩

### 2.1 核心循环

```text
出生 → 买初始装备 → 走向中路
  → 小兵交汇 → 补刀/消耗/躲技能
  → 攒钱回城 → 买装备 → 等级提升
  → 击杀敌方英雄或逼退 → 推塔
  → 推掉两座塔 → 摧毁水晶 → 结算
```

### 2.2 对局节奏

| 时间 | 目标体验 |
|---|---|
| 0:00-0:30 | 出生、买装备、走到线上；第一波兵出发 |
| 0:30-3:00 | 对线期：补刀、抢 2 级、第一次换血 |
| 3:00-6:00 | 第一次回城/出装；小规模击杀；推外塔 |
| 6:00-9:00 | 装备差距显现；内塔攻防；大招博弈 |
| 9:00-12:00 | 水晶推进；胜负结算 |

### 2.3 胜负条件

- **胜利**：敌方水晶生命值降为 0。
- **失败**：己方水晶生命值降为 0。
- **平局/超时**：MVP 不做；如果 15 分钟未结束，可进入“突然死亡”（双方水晶不再回血，防御塔攻击力提升），后续再调。

## 3. 地图与对局规则（数值初稿）

> 单位约等于米；所有数值都是原型期初稿，M2 后按实测调整。

### 3.1 地图布局

```text
蓝方基地                                      红方基地
[泉水 -125] [水晶 -110] [内塔 -80] [外塔 -45]  ……  [外塔 +45] [内塔 +80] [水晶 +110] [泉水 +125]
                        中路宽度约 18m
```

| 元素 | 规格 |
|---|---|

| 兵线长度 | 约 240m（泉水到泉水 250m） |
| 中路宽度 | 18m；两侧有低矮岩石/墙体，限制绕后但不封死 |

| 红方 | 镜像布置 |

| 水晶 | 直径 10m，底座 12m；无攻击能力，由内塔保护 |
| 泉水 | 半径 8m；回血/回蓝；仅在此处打开商店 |
| 地形 | MVP 全平地；两侧岩石用于视觉边界和遮挡，不做高低差 |

## 4. 英雄与技能（首个英雄）

### 4.1 定位

**星辉法师（暂名）**：远程法术输出，靠技能命中叠加被动，擅长中距离消耗和爆发。第一人称下以“直线预判 + 地面落点 + 短位移”为核心，不做复杂近战。

### 4.2 基础属性

| 属性 | 初稿 |
|---|---|
| 生命 | 650 + 90/级 |
| 法力 | 400 + 40/级 |
| 攻击力 | 55 + 3/级 |
| 法术强度 | 0 + 0/级（靠装备） |
| 护甲 | 25 + 3/级 |
| 魔抗 | 30 + 2/级 |
| 移动速度 | 6.5 m/s |
| 普攻射程 | 22m |
| 普攻间隔 | 1.1s |
| 生命回复 | 4/5s |
| 法力回复 | 8/5s |

### 4.3 技能组

| 技能 | 类型 | 数值初稿 | 设计意图 |
|---|---|---|---|
| **被动：奥术回流** | 命中回复 | 技能命中敌方英雄回复 8% 最大法力；每 6s 最多触发一次 | 鼓励用技能换血，不完全依赖蓝量 |
| **Q：秘法飞弹** | 直线 projectile | 射程 24m，速度 30 m/s，宽度 1.2m；伤害 70/110/150/190 + 0.6 AP；冷却 6/5.5/5/4.5s；法力 40 | 第一人称的主瞄准技能；可穿透小兵，命中英雄后停止 |
| **W：滞留法阵** | 地面 AoE | 落点 18m，半径 4m；0.5s 延迟后爆炸；伤害 60/95/130/165 + 0.5 AP；减速 30% 持续 2s；冷却 10/9/8/7s；法力 60 | 练习地面落点；封走位/清兵 |
| **E：相位步** | 短位移 | 向输入方向位移 8m；0.2s 内不可选中；冷却 12/11/10/9s；法力 50 | 躲技能、拉开距离；不做穿墙 |
| **R：棱镜光束** | 持续引导 | 最长 2.5s；光束长 30m、宽 2m；每 0.5s 造成 50/75 + 0.25 AP；引导时移速 -30%；冷却 80/65s；法力 100 | 大招需要站桩瞄准，形成风险/回报 |

### 4.4 普攻

- 左手/右手法杖发射奥术弹，速度 35 m/s，轻微追踪（转角上限 15°/s），保证第一人称下不至于因小误差完全打空。
- 按住左键连续普攻；松开停止。
- 准星附近 3° 内优先锁定敌方英雄，其次小兵，再次防御塔；没有目标时朝准星方向空放。
- 命中反馈：hitmarker、伤害数字、轻微屏幕震动、音效。

### 4.5 等级与技能点

| 项目 | 初稿 |
|---|---|
| 等级 | 1-10 级 |
| 经验来源 | 附近敌方小兵死亡、击杀英雄、推塔 |
| 技能点 | 每级 1 点；Q/W/E 最高 4 级；R 在 5/9 级自动升级，不消耗技能点 |
| 升级奖励 | 基础属性提升；技能点可随时分配（战斗中也可，暂停时不可） |
| 满级时间 | 约 8-9 分钟（正常对线） |

## 6. AI 设计

### 6.1 行为状态

```text
LaneFarm（对线补刀）
  ├─ Harass（消耗英雄）
  ├─ Retreat（低血撤退）
  ├─ Recall（回城补给）
  ├─ Push（推线/推塔）
  ├─ AllIn（斩杀线全技能）
  └─ Dead（死亡等待）
```

### 6.2 决策规则（初稿）

| 场景 | 行为 |
|---|---|
| 己方小兵在附近、敌方小兵可补 | 优先最后一击；否则站安全距离 |
| 敌方英雄进入 18m 且己方血量 > 60% | 用 Q/W 消耗；不越过己方小兵线 |
| 敌方英雄血量 < 35% 且己方技能可用 | 评估斩杀线；E 接近 + Q/W/R |
| 己方血量 < 35% | 后退到内塔后；若敌方跟进则继续退 |
| 己方血量 < 25% 且无威胁 | 回城；买装备后回线 |
| 敌方英雄死亡/回城 | 推线；优先攻击外塔 |
| 玩家在塔下攻击己方英雄 | AI 后撤，避免被塔打 |
| 玩家施放 Q/R | 按难度概率垂直走位/开 E 躲 |

### 6.3 难度参数

| 难度 | 反应时间 | 瞄准误差 | 躲技能概率 | 进攻性 |
|---|---|---|---|---|
| 简单 | 0.7s | 8° | 20% | 0.4 |
| 普通 | 0.4s | 4° | 50% | 0.6 |
| 困难 | 0.25s | 2° | 75% | 0.8 |

- AI 使用和玩家相同的属性、技能、冷却、金币；**不做隐藏数值加成**。
- AI 的“视野”不做全图作弊：只根据距离、兵线、最近可见位置判断。
- 寻路 5 Hz，决策 10 Hz；不要每帧跑 A*。

### 8.4 模拟循环

```text
requestAnimationFrame
  → 累积真实时间
  → while (accumulator >= 1/30) {
      固定 30Hz 更新 sim
      accumulator -= 1/30
    }
  → 用 alpha 插值渲染
```

- 模拟 30 Hz；渲染尽量 60 FPS。
- 单帧最多补 5 个 sim step，避免“死亡螺旋”。
- 渲染层不直接修改 sim 状态；通过事件队列/快照同步。
- 所有伤害、治疗、金币、经验、死亡都走事件，方便 UI/音效/AI 订阅。

### 8.5 物理与寻路

- 玩家：Rapier `KinematicCharacterController`，胶囊体，移动+滑墙；不依赖刚体受力。
- 小兵：沿路点移动 + 简单分离力，避免堆叠；不需要完整刚体。
- 防御塔/水晶：静态碰撞体。
- 投射物：手工球体/线段扫掠检测；不用每颗子弹都进物理世界。
- AI 寻路：MVP 用中路网格 A*（1m 网格）；后续再换导航网格。

### 8.6 资源与性能

| 项目 | 目标 |
|---|---|
| 目标帧率 | 1080p 60 FPS（中端核显/轻薄本） |
| Draw calls | < 250 |
| 三角形 | < 1.5M |
| 同屏小兵 | ≤ 24 |
| 投射物 | 池化 ≤ 100 |
| 动态光源 | 1 方向光 + 环境光；小兵不投实时阴影 |
| 初始包体 | < 15 MB gzip |
| 地图资源 | < 30 MB，按需加载 |
| 内存 | < 300 MB |
| 加载时间 | < 15s（本地/普通宽带） |

优化手段：

- 小兵/投射物用共享几何体和材质；数量上来后再上 `InstancedMesh`。
- 对象池复用投射物、伤害数字、命中特效。
- 纹理用 KTX2/Basis 压缩；模型用 GLB + Draco。
- 小兵阴影用 blob shadow，不开实时阴影。
- 关闭不必要的后处理；只保留轻量 bloom/受击闪屏。
- 处理 `webglcontextlost`；提供画质档位（低/中/高）。

## 9. 里程碑与验收

### M0：可走可打（2-3 天）

**范围**

- Vite + TS + Three.js + Rapier 工程；
- 第一人称移动、鼠标视角、Pointer Lock；
- 灰色盒子地图、碰撞；
- 1 个 projectile、1 个假人；
- HUD 骨架、FPS/ draw call 调试面板。

**验收**

- 能稳定 60 FPS 走完地图；
- 鼠标不飘、不翻转、不穿透地面；
- 左键能打中假人并显示伤害；
- 按 Esc 能释放鼠标、暂停。

### M1：技能闭环（4-5 天）

**范围**

- 4 个主动技能 + 被动；
- 生命/法力/冷却/等级；
- 受击、死亡、复活；
- 简单 AI 假人（会站着反击）；
- 技能 VFX、命中反馈、音效占位。

**验收**

- 4 个技能都能按预期命中/生效；
- 冷却、法力、伤害数字正确；
- 死亡后能复活并回到线上；
- 连续放技能 5 分钟不卡顿。

### M2：一局完整（7-10 天）

**范围**

- 小兵波次、路径、仇恨；
- 两座塔 + 水晶、攻击/减伤/胜利；
- 金币、经验、商店、回城；
- 小地图、战绩、结算；
- 胜负流程。

**验收**

- 可以打完整一局并摧毁水晶；
- 补刀有金币、升级有技能点；
- 塔会转火、会摧毁、会结束比赛；
- 失败/胜利都能一键重开。

### M3：AI 与内容（5-7 天）

**范围**

- 正式对线 AI（补刀、换血、撤退、回城、推塔）；
- 3 档难度；
- 英雄模型/动画/技能特效；
- 地图美术、环境音、UI 美化；
- 设置、按键、存档。

**验收**

- 普通 AI 能赢“完全不操作”的玩家；
- 困难 AI 能躲 Q/R、会越塔判断；
- 一局 8-12 分钟；
- 3 档难度体感明显不同。

### M4：打磨（3-5 天）

**范围**

- 性能优化、画质档位；
- 数值平衡；
- 音效/音乐；
- 新手引导（3 步提示）；
- QA、构建、部署。

**验收**

- 连续 30 分钟无崩溃；
- 目标设备 60 FPS；
- 首次加载 < 15s；
- 设置重启后保留；
- 无控制台报错。

**总计：约 4-5 周单人全职。**  
如果只做“7-10 天可玩原型”，把 M2 砍成“1 波兵 + 1 座塔 + 1 个 AI”，先验证第一人称 MOBA 的核心手感。

## 10. 风险与止损点

| 风险 | 验证时间 | 止损/替代方案 |
|---|---|---|
| 第一人称 MOBA 手感不成立 | M0-M1 | 默认改第三人称；第一人称只做“瞄准/演出”模式 |
| 眩晕/不适 | M0 后找 3-5 人试玩 | FOV/晃动/动态模糊全关；加第三人称；仍不行则改第三人称 |
| AI 太像木桩 | M1 结束 | 先做“会补刀/会后退”的最小 AI；不要一开始做复杂行为树 |
| 小兵/特效拖帧 | M2 | 降同屏小兵数、关阴影、合并材质、对象池 |
| 内容量失控 | 每周评审 | 锁定 1 英雄/1 地图/6 装备；任何新增内容必须砍掉等量旧内容 |
| 第一人称近战难做 | 首版不做 | 远程法师；近战英雄放到 M5 以后 |
| 版权/IP | 全流程 | 原创英雄/地图/音效；不使用 LoL 素材和英雄名 |
| 范围蔓延 | 每周 | MVP 清单之外的需求进入 backlog，不进入当前迭代 |

## 11. 还需要确认的细节

这些不影响现在开工，但会影响美术和内容方向：

1. **美术风格**：低多边形 + 纯色材质（推荐，最快）；还是卡通渲染/写实？
2. **英雄气质**：星辉法师/奥术游侠/元素使，你更喜欢哪种幻想？
3. **UI 语言**：中文优先，还是中英双语？
4. **音频**：先用免费可商用占位音效，还是等你提供素材？
5. **交付方式**：本地 `npm run dev` 即可，还是需要部署到公网（Vercel/GitHub Pages）？
6. **是否需要新手引导**：MVP 建议只做 3 条提示（移动/技能/推塔）。

## 12. 建议的下一步

先做 **M0 灰盒战斗切片**，只验证最危险的假设：

> “第一人称视角下，移动 + 瞄准 + 放技能 + 打兵/打英雄，是否好玩且不晕？”

M0 不碰小兵、塔、商店、AI；只做：

- 一张灰色盒子地图；
- 第一人称移动 + 鼠标视角；
- 一个 Q 技能；
- 一个会动、会反击的假人；
- 一个 HUD 和 FPS 面板。

M0 通过后，再进入 M1。这样即使方向不对，损失也只有 2-3 天，而不是 4-5 周。
